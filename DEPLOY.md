# Инвентаризация для iPhone

Публичный репозиторий содержит только оболочку приложения. Не добавляйте сюда исходные Excel, инвентарные номера, сведения о МОЛ или резервные копии.

## Развёртывание
1. Загрузите в корень репозитория файлы из архива приложения: `index.html`, `app.js`, `sw.js`, `manifest.webmanifest`, `icon.png`.
2. В Settings → Pages выберите Deploy from a branch, `main`, `/(root)`.
3. На iPhone откройте HTTPS-ссылку в Safari, затем «Поделиться» → «На экран Домой».
4. Загрузите исходные Excel непосредственно в установленное приложение.

Перед рабочим использованием проверьте импорт, сохранение после перезапуска, восстановление из JSON, экспорт XLSX и офлайн-режим. Данные браузера могут быть удалены, поэтому сохраняйте резервные копии отдельно.
